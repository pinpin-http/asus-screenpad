# Intégration Omarchy (facultative)

Le paquet principal fonctionne sans Omarchy. Pour le widget intégré à sa barre :

```sh
omarchy plugin add https://github.com/pinpin-http/asus-screenpad.git --enable
```

Ou, avec le paquet Arch déjà installé :

```sh
asus-screenpad-install-omarchy
```

L’activation est conservée dans la configuration de la barre. Pour désactiver :

```sh
omarchy plugin disable soheib.screenpad
```
